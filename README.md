# Project Overview:
This is a team applied industry project (AIP) of creating a financial chatbot given the name "FinOguider" which will be able to answer all financial queries with a click of button, along with a stock analysis bot given then name "FinOlyzer" which will give an overview whether to invest on a particular company or not using graphical representations and calculations.

# Project Purpose & Value to the industry:

Many companies publish data and documents about current status of financial market for the consumers, however understanding and using it without any assistance can lead to loss and scams.

Thus, here the purpose of chatbot is to resolve the financial queries and increase investments opportunity of customers.

Moreover, natural language processing is the prodigy of upcoming artificial intelligence era and this project can aid the industry to move forward and accept the upcoming usage of large language models.
